# Pergoluxe

A premium, enterprise-grade pergola ecommerce platform. Headless Shopify + Sanity CMS on Next.js 15.

This repository currently contains the **project architecture only** — folder structure, tooling configuration, and conventions. No pages or UI have been built yet.

**Start here → [`ARCHITECTURE.md`](./ARCHITECTURE.md)**

It documents the full folder structure, naming conventions, rendering/data patterns, Shopify and Sanity content modeling, design tokens, coding/performance/accessibility/SEO standards, git workflow, and the development roadmap.

## Stack

Next.js 15 (App Router) · TypeScript · Tailwind CSS v4 · shadcn/ui · Framer Motion · GSAP · React Hook Form · Zod · Shopify Storefront API · Sanity · Cloudinary · Resend · Vercel

## Quick start (once dependencies are installed)

```bash
pnpm install
cp .env.example .env
pnpm dev
```
